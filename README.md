# vendas2a

Base do 2A Vendas, o CRM B2B para representantes comerciais (comissões, funil e roteamento de pedidos). O produto publicado está em https://2avendas.com

Este repositório guarda a configuração da aplicação web: TanStack Start, Vite, Tailwind, Supabase, autenticação e deploy na Cloudflare (Wrangler). As telas da aplicação não estão neste commit — só o ferramental de build, lint e publicação.

## Como rodar

```bash
npm install
npm run dev
```
